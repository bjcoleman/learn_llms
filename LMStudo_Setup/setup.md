# Setup LM Studio

> Note: Do not install Bionic from the [lmstudio.ai](https://lmstudio.ai/) homepage. That is a different app. For this course, use LM Studio from [lmstudio.ai/download](https://lmstudio.ai/download).

## Download and Install

1. Open [lmstudio.ai/download](https://lmstudio.ai/download).
2. Click Download for your OS (for example, Download for Mac).
3. Open the installer or app and launch LM Studio.

## First Launch Setup

The first time you open LM Studio, you will see a few setup screens.

### Your first model

One screen offers a default model, recently `gemma-4-e4b` (~6.86 GB). This is the course model, Gemma 4 E4B.

![Your first model](firstmodel.png)

- Click Download gemma-4-e4b to get the course model. It shows up under My Models.
- You can keep going while it finishes in the background.

![Downloading first model](downloadingmodel.png)

If you skipped this screen, you can download Gemma 4 E4B from Discover later (see below).

### Advanced settings

You may see an Advanced settings screen:

![Advanced settings](advancedsettings.png)

For this course:

- Leave Developer Mode off.
- Start local LLM service on login can stay on, or turn it off if you want to save background resources.

Then click Continue to LM Studio →.

### Promo screens

You may see feature promos (for example, LM Link). These are optional. Check Do not show this again, click Next, or close with X.

![Promo screen](promoscreen.png)

## Download a Model

If you already downloaded `gemma-4-e4b` on first launch, you can skip to [Load the Model and Chat](#load-the-model-and-chat). Otherwise:

1. Open Discover → Model Search (or press `⌘⇧M`).

![Model Search](modelsearch.png)

2. Search for `Gemma 4 E4B`.
3. Select the official Gemma 4 E4B result (by Google).
4. Click Download (~6.86 GB; usually about 5 minutes).

![Model Download](modeldownload.png)

If it is already downloaded, you may see Use in New Chat instead.

## Load the Model and Chat

1. Click the Chat icon (or press `⌘1`).
2. Open Select a model to load at the top (or press `⌘L`).

![Select a model to load](chat.png)

3. Choose `Gemma 4 E4B` and wait for it to load.
4. Type a prompt and press Enter.
