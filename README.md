# Learn LLMs in LM Studio

## Lesson order

1. [Setup LM Studio](LMStudo_Setup/setup.md)
   - Install LM Studio, download Gemma 4 E4B, load it, send your first prompt
2. [Tokens and Context](Basics/Tokens/tokens.md)
   - Models read tokens, not words, and every chat has a context length budget
3. [Temperature and Stochastic Sampling](Basics/Temperature/temperature.md)
   - Outputs are sampled from probabilities, and temperature controls the randomness
4. [Preprompting (System Prompt)](Basics/Preprompting/preprompting.md)
   - Standing instructions that shape every reply in a chat
5. [Prompting Techniques](Basics/Prompting/prompting.md)
   - Zero-shot, constraints, few-shot, and vague vs specific prompts
